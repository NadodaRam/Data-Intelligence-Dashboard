# 📊 Sales Data Analysis Dashboard – Excel Project

## 📌 Project Overview
This project is an Excel-based Sales Data Analysis project designed to analyze sales performance, revenue, product demand, regional sales, and monthly revenue trends.

The workbook presents sales insights through a dashboard, summary tables, raw transaction data, and a project report.

## 🎯 Project Objectives
- Analyze total sales revenue and units sold.
- Evaluate sales performance across different regions.
- Understand revenue contribution by product category.
- Identify top-selling products.
- Analyze monthly sales trends.
- Provide business recommendations based on sales performance.

## 🛠️ Tools Used
- Microsoft Excel
- Data Analysis
- Data Visualization
- Dashboard Reporting

## 📁 Project Workbook Structure

| Sheet Name | Description |
|---|---|
| Dashboard | Sales KPIs and visual sales overview |
| Raw Data | Transaction-level sales dataset |
| Summary | Region-wise, category-wise, product-wise and monthly sales summaries |
| Project Report | Key findings and business recommendations |

## 📈 Analysis Included

### Regional Sales Analysis
Comparison of revenue across East, North, West, Central, and South regions.

### Category Sales Analysis
Revenue analysis for:
- Electronics
- Furniture
- Appliances

### Product Performance Analysis
Analysis of units sold across products to identify top-performing products.

### Monthly Sales Analysis
Monthly revenue trends from April 2024 to April 2025.

## 💡 Business Recommendations

- Maintain sufficient inventory of high-demand products.
- Analyze the East region's sales performance to identify growth opportunities.
- Focus on the Electronics category due to its significant revenue contribution.
- Use monthly sales trends to plan promotions and sales strategies.
- Improve customer service and focus on repeat customers.
